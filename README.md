# Exam Emoji Picker

Sélecteur rapide d’émojis pour les cellules d’examens complémentaires dans Obsidian.

## Utilisation

Dans une note Markdown, placez le curseur dans la cellule concernée et utilisez la commande `Choisir un émoji d’examen`.

Le sélecteur propose : 🧪, 🔊, ☣️, 🫙, 📡 et 🧲.

Dans le modèle d’hospitalisation, un bouton `＋` ouvre directement cette liste.

## Installation

Le module peut être installé depuis le catalogue communautaire Obsidian ou avec BRAT depuis ce dépôt GitHub.
